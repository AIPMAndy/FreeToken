三步开始使用

先走官方渠道，避免共享密钥、代充和未知反向代理。

01 · 获取官方 Key

从资源卡片的「进入平台」注册。检查价格页、地区限制、账单要求后再创建密钥。

02 · 确认模型和额度

相同平台下，不同模型的免费资格可能不同。以账号实际控制台的 RPM、TPM、RPD 为准。

03 · 安全试调用

使用环境变量传递 Key；限制账单额度，遇到 429 应遵守 Retry-After。生产环境要有付费降级方案。

OpenRouter 免费模型请求示例

export OPENROUTER_API_KEY="你的密钥"
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"YOUR_CURRENT_FREE_MODEL_ID",
       "messages":[{"role":"user","content":"你好"}]}'

更多开源 AI 网关、云服务与数据 API 请看 扩展生态目录 →。第三方项目不等于官方免费权益。

将 YOUR_CURRENT_FREE_MODEL_ID 替换为模型目录中实际带 :free 后缀的 ID；示例没有嵌入有效密钥。

常见问题

避免对「免费」的常见误解。

免费 ChatGPT 和免费 OpenAI API 是一回事吗？

不是。网页版免费使用权通常不等于 API 调用额度；OpenAI API 应在独立的 Platform Billing 页面确认。

有免费 Key 就可以无限调用吗？

不能。通常还有 RPM、TPM、RPD、按月体验金或模型并发限制，且随账户与模型变化。

为什么旧教程说注册送 500 万 Token？

有些数字只针对历史活动或指定账号。没有现行官方来源的数字已经改为「待核验」，避免误导。

如何避免密钥泄露？

密钥只放服务端环境变量，禁止写入前端 JS、GitHub 公共仓库、截图或聊天记录。泄露后立即撤销并轮换。
