常见问题

避免对「免费」的常见误解。

免费 ChatGPT 和免费 OpenAI API 是一回事吗？

不是。网页版免费使用权通常不等于 API 调用额度；OpenAI API 应在独立的 Platform Billing 页面确认。

有免费 Key 就可以无限调用吗？

不能。通常还有 RPM、TPM、RPD、按月体验金或模型并发限制，且随账户与模型变化。

为什么旧教程说注册送 500 万 Token？

有些数字只针对历史活动或指定账号。没有现行官方来源的数字已经改为「待核验」，避免误导。

如何避免密钥泄露？

密钥只放服务端环境变量，禁止写入前端 JS、GitHub 公共仓库、截图或聊天记录。泄露后立即撤销并轮换。
