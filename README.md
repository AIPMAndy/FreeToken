## 📝 使用建议

### 安全第一
1. **永远不要**在公开代码中硬编码 Token
2. 使用 `.env` 文件或环境变量存储密钥
3. 权限最小化：只授予必要的权限
4. 定期轮换 API 密钥
5. 监控免费额度使用情况

### 省钱技巧
1. **优先用免费模型**：Gemini Flash、DeepSeek、GLM Lite 等
2. **善用免费额度叠加**：注册多个平台，分散使用
3. **缓存结果**：相同请求缓存，减少 API 调用
4. **压缩上下文**：减少 Token 消耗
5. **选择合适的模型**：简单任务用小模型，复杂任务才用大模型

### 推荐组合（日常开发）
```
免费首选: Google Gemini 2.0 Flash (免费层)
中文任务: DeepSeek (极低成本) / 通义千问 (免费额度)
编程任务: Groq + Llama (免费 + 超快)
多模态:  智谱 GLM-4V (免费额度)
图像生成: 即梦 3.0 (免费)
语音合成: MiniMax 海螺 AI (免费额度)
```
