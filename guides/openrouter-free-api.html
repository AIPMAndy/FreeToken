OpenRouter 免费 API 使用教程：:free 模型、日限额与 429

给开发者的免费模型调用说明：怎么找 :free 模型、如何查看真实额度、为什么请求会被限流。

一、真正免费的模型怎么筛选

  1. 进入 OpenRouter 模型目录。
  2. 筛选免费模型并检查模型 ID，通常带 :free 标识。
  3. 在官方账号内创建 API Key；不要从分享群获取陌生 Key。
  4. 发送一次小请求，验证模型当前确实可用。

二、按官方政策理解限额

免费模型目前上限20 RPM、50 请求/日；账户累计购买至少 $10 额度后，免费模型每日上限可升至 1,000。官方也说明失败请求会计入每日额度，负余额可能影响免费模型使用。

免费模型没有生产级可用性保证。应做好失败重试、模型备用及成本上限。

三、curl 测试

export OPENROUTER_API_KEY="YOUR_KEY"
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"YOUR_CURRENT_FREE_MODEL_ID","messages":[{"role":"user","content":"你好"}]}'

模型 ID 需自行从官方当前列表替换。遇到 HTTP 429 不要盲目重试，更不要批量注册绕过限制；按返回的限制信息适当退避。

常见误区

Chat 页面能用并不代表 API 无限制；购买 $10 额度改变免费模型请求上限，也不等于所有模型都免费。带第三方插件或付费模型的请求可能另外收费。
