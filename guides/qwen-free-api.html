阿里云百炼免费 API 领取保姆级教程（2026）

官方明确：北京地域新人免费额度通常有效 90 天；重点教你如何开启用完即停，避免自动扣费。

一、领取前必须知道的 4 个条件

  1. 免费推理额度面向首次开通百炼的用户，限定华北2（北京）地域。
  2. 各模型独立计量，通常每模型 100 万 Token；实际以模型和控制台明细为准。
  3. 通常自开通/模型发布/申请获批之日起 90 天有效；过期失效。
  4. 免费额度只覆盖符合条件的实时推理；Batch、部署、微调等不在抵扣范围。

二、5 步领取和防扣费

  1. 从官方 百炼控制台进入华北2（北京），首次开通服务。
  2. 到免费额度页面，逐项确认模型 ID、剩余额度和到期日。
  3. 已实名认证的账户，请打开免费额度用完即停。官方提醒，认证用户默认可能关闭该开关。
  4. 创建 API Key，使用少量真实请求确认消耗情况。
  5. 每次更换模型或地域后重新确认对应模型是否有免费额度。

三、免费使用最大的坑

对已实名账号，免费 Token 用尽后可能转为按量计费；“用完即停”是必要的风控动作，但配置可能有短暂生效延迟。建议测试结束删除不用的 Key，并定期检查费用与账单。

常见疑问

每个模型能领几次？

一般是按符合资格的模型独立赠送，不能把多个模型的 Token 合并使用。

上海、新加坡地域能用北京的新人额度吗？

官方说明仅华北2（北京）地域模型有对应新人免费额度，其余地域不要预设免费。
