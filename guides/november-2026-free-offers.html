11 月还能领哪些免费 Token？

只收录能在厂商官方页面找到的权益。先区分「通用 API」「限定小程序资源包」「产品内积分」和「免费训练」，不能把四种优惠简单加总成自己的可用 Token。

一、七牛云 Conatus：实名每日 1 亿 Token

官方活动有效期为北京时间 2026-10-24 00:00 至 2026-11-30 23:59。实名认证的用户每天有 1 亿 Token 活动额度，支持 `qiniu/conatus-free`，每日北京时间 00:00 重置，不结转。单笔已到账充值大于 100 元可以将上限提高到每日 10 亿，注意升级不是无门槛免费。

  1. 进入 七牛云官方活动页，登录并确认实名认证资格。
  2. 前往 官方模型详情核对最新活动和模型 ID。
  3. 在七牛云控制台依照官方文档创建自己的 API Key，以 `qiniu/conatus-free` 发送少量测试请求并查看余额。

避坑：该免费模型用完额度会拒绝调用，活动期结束不自动变收费模型；但不提供生产 SLA、也不应拿来保证持续稳定的客户交付。API Key 不要发到聊天群或公共仓库。

二、微信小程序成长计划：一次性 10 亿 Token + 10 万张生图

二期报名窗口为 2026-07-01 至 2026-12-31，通过符合条件的小程序申请后，礼包可在 6 个月内使用。这是限定小程序、云开发相关服务端与控制台的资源包，不是可以任意接入公司后端的通用 AI API 钱包。

  1. 准备微信小程序账号及活动所要求的认证信息。
  2. 进入微信公众平台「行业能力 → 小程序成长计划」申请；确认云开发环境。
  3. 在 腾讯 CloudBase 官方规则核对当前允许的模型、抵扣场景和套餐用尽后的计费方式，再在适用场景调用。

适合谁：确实在做微信小程序 / 小游戏的开发者。外部 Web、通用第三方推理网关、任意外部 Agent 调用都不能默认使用这份赠额。

三、别把产品积分当 API Token

华为云码道 CodeArts Agent：个人体验版 0 元，每月包含 500 套餐积分，当前官方计费说明列出符合条件新用户注册的 4,000 活动积分。积分用于码道代码智能体产品；每日签到积分属于限时活动，数额可调整。参见 官方计费说明。

Fireworks Muse Glimmer 30B：截至 2026-11-30，官方限免指定模型的 SFT/DPO/RL 训练，无需信用卡；但推理和评估调用仍按量计费。参见 Fireworks 官方公告。

四、领取前的 5 项核对

  • 需要实名认证、特定地区、学生身份或已有小程序吗？
  • 是公开 API，还是只能在厂商 App/IDE 内消费？
  • 是否必须绑卡、充值，或者额度耗尽后自动转付费？
  • 截止日、每日重置时间、一次性有效期分别是什么？
  • 允许商用及部署吗？是否存在模型下线、速率与 SLA 限制？
