Hugging Face Inference Providers 还有免费额度吗？（2026）

官方最新说明：普通 Free 用户每月推理积分为 0。PRO 订阅赠额和用户自购额度不能当作免费 API 使用权。

直接结论

官方 Inference Providers 计费文档中，Free Users 每月 Credits 为 None；PRO 用户每月有 $2 计算额度，团队或企业账户另有按席位权益。原先网上常见的“Free 用户每月 $0.10”说法已不适合作为当前公开规则。

现在如何使用 Inference Providers？

  1. 查看 官方最新定价表。
  2. 普通 Free 用户需要先购买计算额度，或升级具备包含额度的 PRO 计划。
  3. 走 Hugging Face Routed Billing 时，符合条件的订阅积分才能按规定抵扣。
  4. 如果配置自己的 Provider Key（BYOK），调用费用来自上游提供商，不能用 HF 的订阅积分抵扣。

替代方案

如果你需要现行公开说明更明确的免费推理入口，可以先研究 OpenRouter 免费模型、Groq 或 Gemini 部分免费模型。它们各有额度限制，不保证长期或无限可用。
